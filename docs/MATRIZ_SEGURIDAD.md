# Matriz de cumplimiento del documento de seguridad

Fuente revisada completa: CAPAS DE SEGURIDAD V2 (1).docx, incluido su diagrama de seis capas. Fecha de revisión: 19 de noviembre de 2026. Alcance: código adjunto y entornos locales aislados expresamente autorizados. No se evaluaron redes ajenas. El alcance de esta entrega se limita a ejecución local.

El texto menciona seis acciones, pero enumera cinco. El diagrama separa mínimo privilegio de identidad y acceso; se incluyeron ambos. HTTPS protege tránsito, no reposo: se registraron controles separados. El documento exige MFA; el código verifica dos pasos por correo, cuya suficiencia como MFA para una plataforma clínica necesita decisión institucional. No se declara cumplimiento total.
